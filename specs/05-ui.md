# 05 — UI

## Surface

One surface in v1: an **injected page overlay** rendered in a shadow root by
`pages/content-ui`. No side panel, no toolbar popup, no options page. The
settings users need live inside the overlay.

## Overlay anatomy

```
┌── overlay ─────────────────────────────┐
│  Mapa nehnuteľností            ⚙  × _ │   ← settings · close · collapse
│  ┌─ map (Leaflet, OSM) ──────────────┐ │
│  │                                   │ │
│  │         📍   📍                    │ │
│  │       📍       ★                   │ │
│  │              📍                    │ │
│  └───────────────────────────────────┘ │
│  Price [0 — 500k €]  Area [0 — 200 m²] │   ← filter sliders
│  ★ 3 favorites · 12/15 listings        │
└────────────────────────────────────────┘
```

### Sizing & position

- Fixed size: 480 × 360. Fixed position: bottom-right, 16 px margin.
- No drag. No resize.
- Collapsed state: a 56 × 56 chip in the same anchor showing the pin count.
- Open/collapsed state persisted as a single global pref in
  `chrome.storage.local` (`overlay.collapsed: boolean`). Not per-hostname.

### Lifecycle

- Mounts when `detectPageType !== 'unknown'`.
- Initial state respects `overlay.collapsed`. Default is open.

### Settings panel

The gear icon opens an inline panel inside the overlay (replaces the map
view while open). Contents:

- **Clear cache** — wipes `geocodes` and `listings` (favorites preserved).
- **Attribution** — `© OpenStreetMap contributors · Geocoding by Nominatim`
  with links.
- **Version** — extension version string.

That's all. No theme switcher, no language switcher (auto-detect from
browser), no diagnostics. Adding more later is a PR away.

## Map

- **Library:** Leaflet, used directly (no react-leaflet — earns no weight
  for the surface area we use).
- **Tiles:** OSM standard `https://tile.openstreetmap.org/{z}/{x}/{y}.png`.
  Attribution control always visible.
- **No marker clustering in v1.** nehnuteľnosti.sk list pages typically
  show ≤ 30 cards. If pin density becomes a real problem, add
  `leaflet.markercluster` then.
- **Initial view:** fit bounds to all geocoded listings on first non-empty
  set; fall back to Slovakia centroid `(48.7, 19.7)` zoom 8 if none yet.
- **Subsequent updates** do not re-fit (no jumpy re-centering).

## Pins

Two visual states:

| State      | Marker             |
| ---------- | ------------------ |
| Geocoded   | filled circle      |
| Favorited  | star               |

No accuracy taxonomy, no precision-warning outline. A pin is a pin.
Selection is conveyed by the open Leaflet popup, not by a separate visual.

### Pin click

Clicking opens a Leaflet popup with a preview built **only from data
already on the listing card** (no detail-page fetches):

```
┌──────────────────────────────────┐
│ [thumbnail]                      │
│  Title of the listing            │
│  149 900 € · 62 m²               │
│  Bratislava, Ružinov             │
│  [ ★ ]  [ ⤴ Show on page ]       │
└──────────────────────────────────┘
```

- **★** toggles favorite (direct IndexedDB write).
- **⤴ Show on page** posts `HIGHLIGHT_LISTING` to the content script; it
  scrolls the listing into view and applies a `mn-highlight` outline class
  for 2 s. Scoped via the shadow root — host page CSS is not modified.
- Clicking the thumbnail or title opens the listing URL in a new tab.

## Filters

Below the map, in the overlay:

- **Price** (EUR): two-handle range slider. Bounds = 10th–90th percentile of
  current `priceEur` values, clamped to round numbers.
- **Area** (m²): same pattern over `areaSqm`.

Filters are client-side, applied to plotted pins. State is per-tab and not
persisted (search context changes between sessions).

No "favorites only" toggle, no listing-type chip row. Filtering by price
and area covers the practical use case; favorites already get a distinct
marker.

## Favorites

- Star button on the preview card. That's the one entry point.
- Persisted as a set of `Listing.id` strings in the `favorites` IDB store
  ([04-geocoding-and-cache.md](04-geocoding-and-cache.md)). Presence is
  truth.
- Favorite pins use the star marker; they are not filtered separately.

## States

| Situation                          | UI                                                          |
| ---------------------------------- | ----------------------------------------------------------- |
| No listings detected               | Overlay hidden.                                             |
| Listings extracted, none geocoded  | Map at SK fallback; small "Geocoding 0/n" badge.            |
| Some geocoded, more pending        | Pins appear incrementally; badge updates.                   |
| Geocoder paused (3× consecutive errors) | Non-blocking inline banner; clears on next success.   |

## Accessibility

- Controls keyboard-reachable. Map receives focus; arrow keys pan (Leaflet
  default).
- Pin popups close on `Escape`.
- High-contrast focus outline.

## Theming

Follow `prefers-color-scheme`. No manual override in v1.
